# Controle de Cabos — Instrumentação e Telecom (U-12)

Painel em um único arquivo HTML (`index.html`) para acompanhar o lançamento de cabos.

- **Cabos de instrumentação**: UDA - Cabos (lista editável) e Resumo por família.
- **Cabos telecom**: TCOM - Cabos (lista editável) e Resumo por família.
- **Anexos**: carregue a planilha atualizada (UDA ou Acompanhamento Telecom) e o painel passa a usar os dados dela. A leitura é feita no navegador.

Abra o `index.html` direto no navegador. Edições de status e estoque ficam salvas no próprio navegador.
